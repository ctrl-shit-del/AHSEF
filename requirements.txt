# AHSEF dependency set.
#
# Torch is pinned WITHOUT a compute suffix on purpose.  The version resolved
# here is the CPU build (2.12.0+cpu) because the development laptop has no
# NVIDIA device; the CUDA profile needs the same version from the CUDA index:
#
#     pip install torch==2.12.0 torchaudio==2.11.0 torchvision==0.27.0 \
#         --index-url https://download.pytorch.org/whl/cu124
#
# Keeping one version number for both builds is what makes the CPU-25% and
# full-CUDA profiles provably the same architecture rather than merely similar.
#
# Every pin below matches the interpreter this was last verified against
# (CPython 3.10.10).

# --- core numeric / data -----------------------------------------------------

# --- deep learning -----------------------------------------------------------

torchaudio==2.11.0
torchvision==0.27.0          # supplies MobileNetV3 for the frozen face encoder

# --- frozen encoders ---------------------------------------------------------
transformers==5.17.0         # RoBERTa-base, text branch

                             # checkpoint; modelscope.cn is unreachable here, so
